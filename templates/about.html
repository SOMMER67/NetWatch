À propos de NetWatch

Présentation du projet

NetWatch est une application web de démonstration conçue pour présenter les principes de la supervision d'un réseau informatique.

Objectifs

  • Afficher les équipements d'un réseau.
  • Consulter leur état de fonctionnement.
  • Visualiser les statistiques de disponibilité.
  • Préparer le signalement des incidents réseau.

Technologies utilisées

  • Python : logique de l'application.
  • Flask : framework web.
  • HTML : structure des pages.
  • CSS : présentation graphique.
  • Docker : conteneurisation prévue.
  • AWS EC2 : hébergement cloud prévu.

Limites actuelles

Les équipements et leurs états sont simulés. Cette version ne réalise pas encore de tests réseau en temps réel.
