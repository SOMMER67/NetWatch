À propos de NetWatch

Découvrez les objectifs, les technologies et les limites de cette plateforme pédagogique.

Présentation du projet

NetWatch est une application web de démonstration conçue pour présenter les principes de la supervision d'un réseau informatique. Elle illustre la conteneurisation et le déploiement cloud avec Docker et AWS EC2.

Objectifs
  • Afficher les équipements d'un réseau
  • Consulter leur état de fonctionnement
  • Visualiser les statistiques de disponibilité
  • Préparer le signalement des incidents réseau
Technologies utilisées
  • Python

    Logique de l'application

  • Flask

    Framework web léger

  • HTML / CSS

    Structure et présentation graphique

  • Docker

    Conteneurisation de l'application

  • AWS EC2

    Hébergement cloud

Limites actuelles
v1.0 — Demo

Les équipements et leurs états sont simulés. Cette version ne réalise pas encore de tests réseau en temps réel. Les signalements sont conservés temporairement en mémoire et disparaissent au redémarrage de l'application.
